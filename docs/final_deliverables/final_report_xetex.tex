\section{摘要}
本项目面向普通用户的移动端三维内容生产场景，构建了从小程序采集、关键帧筛选、云端重建训练、在线预览到点云下载的端云协同流程。系统采用 Spann3R + Splatfacto 的组合架构：前端通过 IMU 稳定性与图像清晰度进行双重关键帧筛选，减少抖动和模糊输入；后端使用 Spann3R 从非标定移动端图像中恢复相机先验和初始点云，再将结果转换为 Nerfstudio 数据格式并进入 Splatfacto / 3D Gaussian Splatting 训练。

本轮结题测试使用桌面视频抽取的 66 张图像作为接近移动端采集的视频输入，系统筛选出 11 个关键帧用于 Spann3R 重建。Spann3R 阶段记录推理速度 11.95 FPS，原始点云 22105 个点，下采样后 864 个点，保留率 3.91\%。Splatfacto 进行 60 步训练后完成 Viewer 预览与 Gaussian splat 导出，导出文件大小约 210.8 KB。与 COLMAP + 3DGS、DUSt3R + 3DGS、NeRF / Nerfacto 的同卡对比表明，本项目方案在当前环境下是唯一完成“采集输入、几何先验、3DGS 训练、在线预览、结果下载”闭环的流程。

\section{项目目标与系统边界}
\subsection{目标}
本项目的目标不是单独复现某个研究算法，而是把移动端采集和云端 3D 重建整合为可演示、可复核、可交付的系统。结题阶段重点验证四个能力：

\begin{itemize}
\item \textbf{上传可用性：}移动端或视频抽帧数据能够进入后端任务队列，训练前输入数量可追踪。
\item \textbf{训练可用性：}非标定图像能够通过 Spann3R 获得相机与点云先验，并被 Splatfacto 继续训练。
\item \textbf{预览可用性：}训练过程和结果能够在 Nerfstudio Viewer 中打开并进行交互观察。
\item \textbf{下载可用性：}结果页面能够区分 raw、downsampled、train、gaussian 等文件类型，并支持单文件或筛选下载。
\end{itemize}

\subsection{本报告取舍}
按照结题展示需要，本文围绕算法路线、训练证据、在线预览和结果下载组织材料。正文不展开部署细节，把重点放在“输入质量控制、非标定重建、3DGS 训练、可视化验证、轻量化交付”这条主线上。

\section{总体技术路线}
系统采用“移动端输入质量控制 + Spann3R 非标定重建 + Splatfacto 高斯训练 + Viewer/点云交付”的路线。其核心原因是：手机图像往往缺少稳定外参和规范采集轨迹，直接使用传统 COLMAP 或直接进入 3DGS 训练，容易受到模糊、抖动、遮挡和重复帧影响；Spann3R 能够先从图像序列中提供相机和点云先验，再交给 Splatfacto 优化高斯表达，从而把研究算法变成更接近产品流程的端到端系统。

\section{移动端采集与首页优化}
前端首页已从联调面板调整为正式采集工具界面。原页面常驻显示 IMU 方差、Acc/Gyro、阶段说明和调试文本，信息密度高但对普通用户不友好。优化后首页保留相机全屏画面，只在顶部显示三类核心状态：“稳定/请持稳”“双筛关键帧采集”“后端就绪/等待服务”；双重筛选以“稳定性筛选”和“清晰度筛选”两个状态项表达；采集统计压缩为“有效帧 / 总帧”与“晃动 / 模糊”淘汰摘要。

该调整没有改变拍照间隔、IMU 阈值、模糊阈值、上传门控和上传接口，主要解决首页看起来像调试面板的问题。个人微信小程序端仍保持原有外部跳转与复制方案，不使用 WebView。

\section{算法与训练结果}
\subsection{Spann3R 阶段}
Spann3R 阶段从 66 张上传图像中按关键帧间隔采样出 11 个关键帧，用于恢复相机先验和点云。日志记录显示重建完成，推理速度为 11.95 FPS。点云处理结果为：原始点云 22105 个点，下采样后 864 个点，保留率 3.91\%。这说明系统没有把完整噪声点云直接交给后续训练与下载，而是形成了更轻量的中间表达。

\subsection{Splatfacto / 3DGS 阶段}
Splatfacto 训练使用 Spann3R 转换后的 Nerfstudio 数据集，完成 60 步训练并生成 checkpoint。训练日志显示第 10、20、30、40、50 步的 Train Rays/s 分别为 134.26M、126.81M、117.25M、114.61M、116.25M。短迭代测试的意义不是追求最终视觉质量上限，而是证明转换、训练、Viewer 和导出链路能够稳定闭合。

对比结果体现了本项目架构的工程价值：传统 COLMAP + 3DGS 对外部几何工具依赖强；DUSt3R 独立 demo 在依赖环境上更容易与现有训练环境冲突；NeRF / Nerfacto 能跑训练，但更偏神经场渲染基线，不直接解决本项目的 Gaussian 结果交付目标。Spann3R + Splatfacto 则在本轮环境中完成了从非标定帧输入到 Gaussian 下载的完整链路。

\section{结论}
本项目结题阶段已经具备可演示闭环：前端采集首页从调试面板优化为正式采集工具；上传链路能够处理多帧输入；Spann3R 能够从移动端/视频帧中恢复关键帧几何先验；Splatfacto 能继续训练并打开 Viewer；下载页面能够交付 raw、downsampled、train 和 Gaussian 文件。整体架构的优势在于将非标定移动端输入、先验重建和 3DGS 训练衔接成可复核流程，而不是停留在单个算法脚本。

后续答辩可重点展示三条证据线：第一，首页的双筛关键帧采集界面，说明输入质量控制；第二，训练时间线、吞吐曲线和 Viewer 截图，说明训练可跑且可预览；第三，下载页面和点云体积对比，说明结果可交付且下载方案经过优化。
